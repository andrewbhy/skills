Agent tooling

Rules and checks agents run

These help agents catch problems before you see a mockup. Open a guide to see a real finding and the rule behind it.

  • Theme builder

    Builds a complete theme and avoids missing colour roles. Runs when preparing a theme for a build or mockup · jig-build, jig-mockup.

  • Theme checker

    Catches unreadable text and layers that blend together. Runs after theme edits and during interface review · jig-verify, jig-review.

  • Spacing and craft checks

    Catches margin errors, stray values and missing control states before you see a mock. Runs before mockup feedback and during interface checks · jig-mockup, jig-verify, jig-review.

  • Craft basics

    Catches uneven grouping, misplaced controls and confusing labels. Runs during building and screenshot review · jig-mockup, jig-verify, jig-review.

  • Motion vocabulary

    Puts an exact name to the effect you have in mind. Runs when describing an effect, before a brief or motion ledger is built · jig-mockup.

  • Motion recipes

    Gives ordinary controls a consistent response. Runs when building menu, popover, tooltip, dialog, toast, disclosure, tab or press feedback · jig-mockup.

  • Motion basics

    Catches unexplained changes, distracting repetition and broken replay. Runs when choosing motion and reviewing it in frames · jig-mockup, jig-verify, jig-review.

  • Component checklist

    Catches missing states, lost focus and long-text failures. Runs before a component becomes a reference others copy · jig-mockup, jig-verify, jig-review.
