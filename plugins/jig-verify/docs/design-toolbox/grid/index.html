One scale, eight steps

The bars are actual CSS pixel lengths. Use the named token for padding, margin and gap. Zero space uses --grid-space-0. The inner gap is 8 px; choose 24 or 32 px between groups. A container uses one inset token.

  • --grid-space-14 px
  • --grid-space-28 px · inner gap
  • --grid-space-312 px
  • --grid-space-416 px · default inset
  • --grid-space-624 px · gutter / outer gap
  • --grid-space-832 px · roomy outer gap
  • --grid-space-1248 px
  • --grid-space-1664 px

This guide opts into the Vast example type roles: meta 12/16, code 14/20, content 15/24, title 18/24 and numeral 24/32 px. The page heading is a separate fixed 32/32 guide role. Other projects declare their own scale. Neither type nor spacing scales with viewport width.

Compose small layouts

Load tokens.css, then primitives.css. Put data-grid on an ancestor. The classes choose layout only; your project supplies typography, colour and controls. These examples use the real primitives.

<div data-grid class="grid-stack">
  <div class="grid-cluster">…</div>
  <article class="grid-panel grid-reading">…</article>
</div>

Reading column · stop at 72ch

.grid-reading fills its available space and stops at 72ch. This approximates a readable measure; the actual number of characters depends on the font.

Long prose stays comfortable while the surrounding board can keep growing. Narrow regions wrap text instead of reducing its size. User text-spacing settings must remain free to expand the content.

Region

Use .grid-region-container > .grid-shell for rail, main, side and second pane. Place .grid-region on main and .grid-columns inside it. The grid owns inline margins once; do not add another inset around it. Drawers and sheets require behaviour: this demo moves the same panel into one native modal dialog, preserving its inputs and restoring it on close.

The width class is a maximum visible set. For content needing more room, set data-grid-collapse="second", then "side", then "rail" on the shell. This is a project content decision. The demo uses rail 64, main minimum 320, inspector 280 and second pane 320 px; these are prototype geometry defaults, not published rules.
