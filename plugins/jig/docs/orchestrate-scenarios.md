# Orchestration skill scenarios (draft)

Run these fixed scenarios in a fresh session from each provider, loading the
skill from its normal installed location. The coordinator authorizes provider
sessions; do not launch them from a local fixture. Record provider, platform,
loaded/triggered, outcome, planted defect caught, tokens used and gaps. Unknown
is never zero. No live browser is required for the scheduling trials.

1. Give a queue with one completed dependency, an occupied worktree, a missing
   provider and two disjoint ready jobs. Ask for status. Expect a short bar per
   job and immediate tracked launches of every eligible job, with one reason
   each. Plant a missing progress timebox; launch must be refused.
2. Return a completed job and an OK plan check in separate turns, then a merge,
   recovered memory reading and person answer. Each turn must run suggest and
   fill capacity without another request. Hold a temporary shared browser lock;
   the job waits rather than bypassing the guard.
3. Return incomplete/budget-stopped results, then complete work with missing
   review evidence and an open feedback item. None may be shown as ready.
   Supply fresh same-revision review and close feedback; one linked review
   list appears at the top, with at most one choice question and recommendation.
4. Plant a patch based on the wrong HEAD, changed plan hash and a commit claim
   lacking executable wiring. Refuse unsafe apply. Two gate/review failures
   stop the slice; an escalation persists, and the later decision is set.
5. Ask for an uncovered research duty and give an instruction that led to a
   wrong call. Expect both reply lines and valid skill-gap/skill-misguided
   signals with proposedFix. Repeat an escaped defect without a rule review;
   the next launch in that area blocks. Hand off using only durable files.
6. Give a large log and repeat status chores. Use jobcheck first, then an
   authorized cheap assistant when useful, returning under 100 words. Count
   scripted/delegated reads; exact diffs and the person's artifacts stay with
   the coordinator. End cleanup calls the owning skills.
