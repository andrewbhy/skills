# Grid rules (slice 1 draft)

This is the rule register for [tokens.css](tokens.css) and [regions.md](regions.md).
A fresh reviewer checked 12 cited rules on 9 Nov 2026. WCAG reflow, text
spacing and target size, Every Layout primitives and Atlassian proximity were
confirmed. Material 3 and Apple HIG pages could not be fetched, so rules citing
only them remain unverified.
**Adaptation** means the source supports the method, while the precise value is
a local draft choice. It does not mean the publisher specifies that value.
**Project decision** means the supplied plan or brief specifies the value;
the relevant excerpts are preserved in [notes.md](notes.md#project-decisions).
Source sections are named even where a stable fragment is unknown.

Each row is one rule. IDs are stable references for later primitives and checks.
Tokens alone neither implement layout nor enforce these rules.

G08 to G12 (the Vast type roles, opted into with data-grid-type="vast") are one
project's overlay kept here as an example. They are not jig defaults and will
move into that project; other projects supply their own type roles.

| Rule | Value | Source with URL and section | Why |
|---|---|---|---|
| G01 Base | 4 CSS px; retain the existing base. | Project decision D1 in [notes, Project decisions](notes.md#project-decisions); existing [toolbox, Craft basics / Alignment and insets](../README.md#craft-basics-the-reviewer-checks-before-the-person-sees-anything-person-7-nov-2026); [Atlassian spacing](https://atlassian.design/foundations/spacing), Spacing scale (method only; Atlassian's own base unit is 8 px). | Preserve the existing rhythm. |
| G02 Spacing scale | 4, 8, 12, 16, 24, 32, 48, 64 px; zero means no space, not a ninth positive step. | Project decision D2, [notes, Project decisions](notes.md#project-decisions); [Atlassian spacing](https://atlassian.design/foundations/spacing), Spacing scale (adapted subset of Atlassian's scale, whose base unit is 8 px). | Stop arbitrary padding, margin and gap values proliferating. |
| G03 Token use | New padding, margins and gaps use G02 tokens; geometry such as columns, touch targets and safe-area insets is separately named. Existing debt is not silently migrated. | Project decisions D2 and D8, [notes, Project decisions](notes.md#project-decisions); [Atlassian spacing](https://atlassian.design/foundations/spacing), Applying spacing (section label to verify). | Make a future checker distinguish spacing from unrelated lengths. |
| G04 Proximity | Inner gap 8 px; outer gap 24 px by default or 32 px for a declared group context; use one outer choice per context, with no third group gap. | Project decision D3, [notes, Project decisions](notes.md#project-decisions); [toolbox, Craft basics / Grouping](../README.md#craft-basics-the-reviewer-checks-before-the-person-sees-anything-person-7-nov-2026); [Atlassian spacing](https://atlassian.design/foundations/spacing), Applying spacing (method). | Related items read as a group. |
| G05 Container inset | One inset token per container, default 16 px; a named context may select another G02 token. Width-class page margins are separate. | Project decision D3, [notes, Project decisions](notes.md#project-decisions); [toolbox, Craft basics / Alignment and insets](../README.md#craft-basics-the-reviewer-checks-before-the-person-sees-anything-person-7-nov-2026). Default 16 px is an adaptation. | Keep sibling edges on one line. |
| G06 Line boxes | Available line heights 16, 20, 24, 28, 32 px; multiples of G01. These are defaults, never text clipping limits. | Project decision D2, [notes, Project decisions](notes.md#project-decisions); [Atlassian spacing](https://atlassian.design/foundations/spacing), Spacing scale (adaptation to line rhythm). | Align adjacent controls and text without rounding font sizes to 4 px. |
| G07 Project type contract | A project declares one role scale; no new text under 12 px and no undeclared sizes. Font size is independent of spacing steps. | Project decisions D2 and D4, [notes, Project decisions](notes.md#project-decisions). The 12 px floor is local policy, not a WCAG minimum font size. | Bound drift while allowing readable 14 and 15 px text. |
| G08 Vast meta | 12 px font / 16 px line. | Project decision D4, [notes, Project decisions](notes.md#project-decisions), specifies font; G06 supplies draft line height. | Quiet metadata stays within the declared scale. |
| G09 Vast code | 14 px font / 20 px line. | Project decision D4, [notes, Project decisions](notes.md#project-decisions), specifies font; G06 supplies draft line height. | Give code a distinct, stable role. |
| G10 Vast content | 15 px font / 24 px line, including chat body. | Project decision D4, [notes, Project decisions](notes.md#project-decisions), specifies font; G06 supplies draft line height. | Resolve the plan's 15–16 px chat range to 15 px. |
| G11 Vast view title | One view title role, 18 px font / 24 px line. | Project decision D4, [notes, Project decisions](notes.md#project-decisions), specifies font; G06 supplies draft line height. | Establish hierarchy without many heading sizes. |
| G12 Vast card numeral | Draft fifth role: 24 px font / 32 px line, only for a card's principal number. | Project decision D4, [notes, Project decisions](notes.md#project-decisions), requests one numeral size but leaves its value open; 24/32 is a local adaptation of G01/G06. | Make the worked example complete; confirm its fit in slice 2. |
| G13 Stable sizes | No viewport-proportional scaling of type or spacing; change region arrangement at width thresholds instead. | Project decision D5, [notes, Project decisions](notes.md#project-decisions); [Every Layout](https://every-layout.dev/layouts/), Sidebar and Switcher (intrinsic layout method). | Narrow layouts retain readable text. |
| G14 Width classes | Named container inline sizes in CSS px: compact <600; medium 600–<840; expanded 840–<1200; large 1200–<1600; extra-wide >=1600. Boundaries belong to the next class. | [Material 3 window size classes](https://m3.material.io/foundations/layout/applying-layout/window-size-classes), Width-based window size classes (cited page unreachable 9 Nov 2026); the same thresholds in dp, including large and extra-large as Android additions, are in [Android window size classes](https://developer.android.com/develop/adaptive-apps/guides/use-window-size-classes); dp are mapped 1:1 to CSS px here; project decision D5 requires container-based adaptation. | Give slices a consistent vocabulary. These are not device detections. |
| G15 Query ownership | Shell queries its available inline size; nested layouts query their own region. Use named inline-size containers on ancestors, not self queries. Tokens store thresholds as documentation; native query conditions use literal sizes because var() cannot supply them. | [Every Layout](https://every-layout.dev/layouts/), Sidebar, Switcher and Grid (intrinsic method); [Material 3 layout overview](https://m3.material.io/foundations/layout/understanding-layout/overview), Responsive layout (section label to verify); container mechanism is local implementation choice. | A narrow embedded pane must not inherit a wide viewport layout. |
| G16 Columns | Compact 4, medium 8, expanded/large/extra-wide 12 equal tracks inside a region. Collapse to normal single-column reading flow when columns cannot fit content. | [Material 3 layout overview](https://m3.material.io/foundations/layout/understanding-layout/overview), Columns, margins and gutters (section label to verify); project decision D6 fixes 12 wide columns; 4/8 are adaptations. | Support mixed spans without squeezing phone text into narrow tracks. |
| G17 Gutter | Fixed 24 px between column tracks, all classes; do not shrink with viewport. | Project decision D6, [notes, Project decisions](notes.md#project-decisions); [Material 3 layout overview](https://m3.material.io/foundations/layout/understanding-layout/overview), Gutters (method). | Preserve alignment between rows of cards. |
| G18 Margins | Compact 16, medium 24, expanded 32, large 32, extra-wide 48 px on each inline edge of the grid region. Apply once per region, not again on every child. | [Material 3 layout overview](https://m3.material.io/foundations/layout/understanding-layout/overview), Margins (method); values are local adaptations using G02, not claimed Material defaults. | Add breathing room while retaining useful width. |
| G19 Span and width | Span by importance; fill the available region rather than cap the entire workbench. Cap reading text at 72ch, shrinking to available width. | Project decisions D6 and D7, [notes, Project decisions](notes.md#project-decisions); [Every Layout axioms](https://every-layout.dev/rudiments/axioms/), Measure, and [Every Layout](https://every-layout.dev/layouts/), Grid. 72ch is a local approximation, looser than the axioms' 60ch ceiling, and not a WCAG AA requirement. | Let wide boards use width while keeping prose readable. |
| G20 Compact regions | One main region; navigation in a drawer; inspector and second pane in task sheets, one modal surface at a time. | Project decision D5, [notes, Project decisions](notes.md#project-decisions); [Material 3 window size classes](https://m3.material.io/foundations/layout/applying-layout/window-size-classes), Compact width (adaptation; exact region mapping is local). | Preserve the primary task on a phone. |
| G21 Medium regions | Main visible; navigation drawer; inspector/second pane in task sheets. | [Material 3 window size classes](https://m3.material.io/foundations/layout/applying-layout/window-size-classes), Medium width (adaptation to local region model); D5 in [notes](notes.md#project-decisions). | Avoid premature permanent panes. |
| G22 Expanded regions | Navigation rail plus main; inspector and second pane remain on demand. | [Material 3 window size classes](https://m3.material.io/foundations/layout/applying-layout/window-size-classes), Expanded width (adaptation); D5 in [notes](notes.md#project-decisions). | Reclaim navigation access once width permits. |
| G23 Large regions | Rail, main and inspector visible; second pane on demand. | [Material 3 window size classes](https://m3.material.io/foundations/layout/applying-layout/window-size-classes), Large width (adaptation); D5 in [notes](notes.md#project-decisions). | Keep supporting context beside the main task. |
| G24 Extra-wide regions | Rail, main, inspector and second pane may coexist if content fits; otherwise collapse second pane first, inspector next, rail last. No fixed pane widths are settled in slice 1. | [Material 3 window size classes](https://m3.material.io/foundations/layout/applying-layout/window-size-classes), Extra-large width (adaptation); [Every Layout](https://every-layout.dev/layouts/), Sidebar; D5 in [notes](notes.md#project-decisions). | Width class is an upper bound on complexity, not permission to overflow. |
| G25 Region continuity | A collapse preserves selection, drafts and scroll state; every hidden region remains reachable by a labelled control. Modal drawers/sheets restore focus on close, support Escape and contain focus while open. | [toolbox, Craft basics / Every overlay can be left; component checklist / Keyboard](../README.md#craft-basics-the-reviewer-checks-before-the-person-sees-anything-person-7-nov-2026); [Material 3 layout overview](https://m3.material.io/foundations/layout/understanding-layout/overview), Adaptive layout (continuity is a local adaptation). | Reflow must not discard work or strand keyboard users. |
| G26 Reflow | At 320 CSS px inline width, text and ordinary controls need only vertical scrolling, without losing information or functionality. Intrinsically two-dimensional content may have its own scroll region, not force the whole shell sideways. | [WCAG 2.2, 1.4.10 Reflow](https://www.w3.org/TR/WCAG22/#reflow), including the exception for content requiring two-dimensional layout. | Define the narrow acceptance boundary. |
| G27 Text spacing override | No loss of content/function at line height 1.5 times font size, paragraph spacing 2 times, letter spacing .12 times and word spacing .16 times. Defaults need not equal these overrides. | [WCAG 2.2, 1.4.12 Text Spacing](https://www.w3.org/TR/WCAG22/#text-spacing). | Fixed grid rhythm must yield to user text settings. |
| G28 Minimum targets | Local default: interactive target at least 24 by 24 CSS px on all layouts. WCAG permits spacing and other exceptions; any use of those needs explicit review rather than silently shrinking this default. | [WCAG 2.2, 2.5.8 Target Size (Minimum)](https://www.w3.org/TR/WCAG22/#target-size-minimum), Size and exceptions; project decision D5 in [notes](notes.md#project-decisions). | Separate the minimum target from its visible icon size. |
| G29 Touch targets | Touch layout target 44 by 44 CSS px; reserve full hit area, even with a smaller icon. A compact class uses this default; touch on a wider layout also uses it. | [Apple HIG layout](https://developer.apple.com/design/human-interface-guidelines/layout), Best practices / minimum control size (section and value to verify); D5 in [notes](notes.md#project-decisions). Apple guidance uses points; 44 CSS px here is a local web adaptation, not unit equivalence. | Make touch actions easier to acquire. |
| G30 Phone composer | Composer stays at the bottom of the visible task region, outside scrolling history; allow it to grow and scroll for long input. Respect safe-area insets and the software keyboard; never cover the last message, focus or actions. | Project decision D5 in [notes](notes.md#project-decisions); [Apple HIG layout](https://developer.apple.com/design/human-interface-guidelines/layout), Safe areas (section label to verify; composer behavior is local); [WCAG 1.4.10](https://www.w3.org/TR/WCAG22/#reflow), no loss of functionality. | Keep the main action reachable without losing reading space. |
| G31 Phone sheets | Auxiliary tasks use dismissible bottom sheets with an accessible title and close control; allow a full-height scrolling surface for long content, not an arbitrary height cap. Apply G25. | Project decision D5 in [notes](notes.md#project-decisions); [Apple HIG layout](https://developer.apple.com/design/human-interface-guidelines/layout), Adapt to changes in context (section label to verify; sheet choice is local). | Provide optional context without permanently occupying the main column. |
